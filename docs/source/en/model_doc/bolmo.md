# Bolmo

Bolmo is a byte-level language model "byteified" from [OLMo3](./olmo3). Bytes go through a small mLSTM encoder, a
boundary predictor groups them into patches, the OLMo3 decoder stack runs on patches, and an mLSTM decoder predicts
the next byte. A byte id shifted by `vocab_size // 2` marks the end of a patch.

The tokenizer returns `expanded_input_ids` (the longest subword ending at each byte) next to `input_ids`. Pass the
tokenizer to `generate`, it is needed to expand every generated byte.

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("allenai/Bolmo-7B")
model = AutoModelForCausalLM.from_pretrained("allenai/Bolmo-7B", dtype="auto", device_map="auto")

inputs = tokenizer("Language modeling is ", return_tensors="pt").to(model.device)
output = model.generate(**inputs, tokenizer=tokenizer, max_new_tokens=64)
print(tokenizer.decode(output[0], skip_special_tokens=True))
```
